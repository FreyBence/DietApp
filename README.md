# DietApp

> Note: This repository is a research project developed for my Bachelor's degree. The code and documentation here were created to support the research, experiments, and evaluation described in the accompanying thesis.

One-line summary
---------------
DietApp is a C# application that helps users log and analyze dietary intake and nutrition-related data. It was developed as part of an academic research project (Bachelor's thesis) to investigate personalized diet plan analysation and enchancement.
